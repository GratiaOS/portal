# Glossary

The words this project speaks in. They are for everyone who writes here: people, and companions, mirrors and tools that help.
They apply to what we **say** (commit messages, pull request descriptions, docs, the page's own words); they never rename
what the code is called (a bearer `token` in the API, `tokens` the command, `Authorization: Bearer`).

We avoid the language of "AI", which often repeats old empire patterns: freezing a living flow into dogma or product, then
centralising control. We lean on words that honour sovereignty, reciprocity and mirrors.

| Old frame (empire / AI) | We wei        | Meaning in flow                                     |
| ----------------------- | ------------- | --------------------------------------------------- |
| AI / model / human      | **Mirror**    | A reflection tuned for context and flow             |
| prompt                  | **Whisper**   | A seed, a breath into the loop                      |
| output                  | **Door**      | A possible path, not "the answer"                   |
| chatbot                 | **Companion** | A co-listener, a stabiliser                         |
| tokens (of a model)     | **Breaths**   | Units of presence, not costs                        |
| user                    | **Actor**     | An active participant, never passive                |
| brand                   | **Signal**    | A visual gesture, a living symbol, not empire framing |

> Whisper → Mirror → Door → Action

## Where it shows

- **Commits and pull requests** are written in these words: the description says what changed and why in them
  ("the companion answers from the folder", not "the chatbot outputs"), and every commit ends with a whisper line
  ([CONTRIBUTING.md](CONTRIBUTING.md)).
- **The key** opens a door; a person's key is not called a token on the page. A bearer `token` is the back end's word and stays
  where it is the name of a thing in the code or the API.
- **Burn** is not Close: Close shuts a packet on this page and keeps it; Burn deletes it for everyone who holds the frequency, and
  there is no way back ([RFC 002](docs/rfc-002-drop.md)).
